## 🚀 Функциональность

- [x] **Адаптивный дизайн** — корректное отображение на ПК, планшетах и смартфонах, включая интерактивное бургер-меню для мобильных устройств.
- [x] **Продвинутые анимации** — плавная левитация 3D-графики на главном экране (CSS keyframes) и каскадное появление контента при загрузке.
- [x] **Эффект "Свет за курсором"** — футуристичное неоновое свечение, которое плавно следует за указателем мыши (JS + CSS Radial Gradient).
- [x] **Умный скролл-трекер** — автоматическая подсветка активного пункта меню навигации в шапке при прокрутке страницы (Intersection Observer API).
- [x] **Сбор заявок в LocalStorage** — форма обратной связи валидирует данные, формирует JSON-объект и сохраняет историю обращений локально в браузере.

## 📁 Структура проекта

```text
├── css/
│   └── style.csstxt     # Стили, неоновая палитра и тайминги анимаций
├── js/
│   └── script.js       # Логика трекинга мыши, скролла и LocalStorage
├── img/                # Папка для локальных изображений, логотипа и favicon
└── index.html          # Главная страница сайта-визитки
```

## 🎨 Используемые технологии

- **HTML5** — семантическая разметка документа.
- **CSS3** — Flexbox/Grid-сетки для адаптивности, кастомные переменные, CSS-анимации.
- **Vanilla JavaScript** — чистый JS без использования тяжелых сторонних библиотек.

## 🌿 Git-ветки

- `main` — стабильная, релизная версия сайта.
- `development` — ветка для активной разработки и добавления новых секций.
- `test` — эксперименты со сложными анимациями и шейдерами.

## 🌐 Развертывание

Сайт оптимизирован для работы с **GitHub Pages**:
1. Перейдите в `Settings` -> `Pages` вашего репозитория.
2. В качестве источника выберите ветку `main` и корневую папку `/ (root)`.
3. Нажмите `Save` — через пару минут сайт будет доступен в сети.
